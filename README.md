# كوكي بارك — Malahy

**نظام قطع التذاكر وحساب المبيعات اليومية** للمدينة الترفيهية — تطبيق سطح مكتب بواجهة عربية كاملة.

الإصدار الحالي: **2.4.6**

---

## نظرة عامة

تطبيق «كوكي بارك» مخصص لقطع تذاكر المدينة الترفيهية وحساب المبيعات اليومية بشكل دقيق وفوري،
مع تقارير قابلة للتصدير والطباعة، ونظام تفعيل يحمي النسخة المثبّتة، وتحديثات إلزامية تضمن
تشغيل أحدث إصدار دائمًا على الأجهزة.

## الميزات الرئيسية

- **قطع التذاكر**: إصدار تذاكر سريع مع طباعة الإيصال مباشرة على الطابعة المختارة.
- **حساب المبيعات اليومية**: تتبّع دقيق للمبيعات والمصروفات والهدايا مع أرصدة محدّثة لحظيًا.
- **التقارير**: تصدير التقارير بصيغة PDF و Excel (CSV) مع دعم كامل للغة العربية.
- **قاعدة بيانات محلية**: تخزين كل البيانات في ملف JSON داخل مجلد بيانات المستخدم،
  ولا تتأثر بمسح بيانات المتصفح وتبقى محفوظة بعد التحديث.
- **نظام التفعيل (Activation Lock)**: غطاء تفعيل مقفول لا يمكن تجاوزه إلا بكود التفعيل الصحيح،
  مع فخ تركيز ومنع الوصول للواجهة خلفه.
- **بوابة التحديث الإجباري (Mandatory Update Gate)**: عند توفر إصدار أحدث لا يمكن فتح
  الواجهة الرئيسية حتى يكتمل التحديث — شاشة مقفولة بدون أي خيار للتخطّي.
- **التحديث التلقائي**: يعتمد على GitHub Releases لجلب أحدث إصدار وتنزيله وتثبيته تلقائيًا.
- **قفل نسخة واحدة**: منع تشغيل أكثر من نسخة من البرنامج في نفس الوقت.

## التقنيات

| الغرض | التقنية |
| --- | --- |
| إطار العمل | Electron |
| التحديثات | electron-updater (مزوّد GitHub) |
| التخزين | ملف JSON محلي (بدون مكتبات خارجية) |
| التعبئة | electron-builder (هدف NSIS x64) |

## البنية

```text
.
├── main.js            العملية الرئيسية (النوافذ + IPC + المنطق)
├── preload.js         الجسر الآمن بين الواجهة والعملية الرئيسية
├── database.js        التخزين المحلي (JSON)
├── activation.js      منطق غطاء التفعيل (مكتفٍ ذاتيًا)
├── update-gate.js     منطق بوابة التحديث الإجباري (نقي وقابل للاختبار)
├── index.html         الواجهة الرئيسية
├── windows/
│   ├── splash.html    شاشة البدء
│   └── update.html    شاشة التحديث الإجباري المقفولة
├── assets/            الأيقونات والصور
├── electron-builder.yml   إعداد البناء والإصدار
└── dist/              مخرجات البناء (محلية فقط)
```

## التطوير

```bash
npm install        # تثبيت الاعتمادات
npm start          # تشغيل التطبيق في وضع التطوير
```

## البناء والإصدار

```bash
npm run dist       # بناء مثبّت NSIS x64 بدون النشر
npm run publish    # بناء + نشر تلقائي على GitHub Releases
```

مثبّت Windows الناتج: `dist/malahy-setup-2.4.6.exe`

## آلية التحديث

1. التطبيق يقرأ إعداد النشر من `electron-builder.yml` (المزوّد: GitHub،
   المستودع: `sliveamer20/malahy`).
2. يفحص `latest.yml` المنشور مع كل إصدار على GitHub ويقارن رقم الإصدار.
3. عند توفر إصدار أحدث: تُفتح بوابة التحديث الإجباري، ويُنزَّل التحديث ثم يُعاد
   التشغيل تلقائيًا — ولا يمكن الوصول للواجهة الرئيسية قبل اكتمال ذلك.
4. إذا تعذّر الوصول للخادم وكانت النسخة المثبّتة أقدم من الحد الأدنى المسموح،
   تبقى الواجهة مقفولة مع رسالة واضحة وخيار إعادة المحاولة.

## معلومات الإصدار

- **الإصدار**: 2.4.6
- **الحد الأدنى المسموح لتشغيل الواجهة (Floor)**: 2.4.6
- **الهدف**: Windows x64 (NSIS)

### أبرز تغييرات 2.4.6

- **حماية التفعيل**: غطاء تفعيل مقفول مع تشفير الكود وفخ تركيز ومنع الوصول للخلفية.
- **التحديثات الإلزامية**: بوابة تحديث لا يمكن تخطّيها قبل فتح الواجهة الرئيسية،
  مع حالة أوفلاين واضحة وإعادة محاولة.
- **تحسينات الاستقرارية**: معالجة أخطاء غير مقبوضة سابقة (unhandled rejections)،
  تنظيف المؤقتات، وحماية استدعاءات النوافذ بعد إغلاقها.
- **تحسينات الواجهة**: نظام تصميم محدّث، شاشة بدء متوافقة مع ألوان الواجهة،
  ودعم الطباعة وفتح الروابط الخارجية.
